# MAKERSENSE 工作台 使用說明

一個視窗同時用 Claude 和 Codex（GPT）開發產品，兩邊都用你自己的月費帳號，不用付費 API。

## 第一次安裝（只做一次）

1. 把整個 `MAKERSENSE_Workbench` 資料夾解壓縮到 `D:\FDM\Claude\`（結果是 `D:\FDM\Claude\MAKERSENSE_Workbench\`）。
2. 打開這個資料夾，雙擊 **「MAKERSENSE 工作台」** 捷徑。
3. 第一次開會自動在 **桌面** 和 **開始功能表** 建立「MAKERSENSE 工作台」捷徑，之後從桌面開就好。

> 如果放在別的位置：資料夾裡的捷徑會失效，改成雙擊 `launch.vbs`，桌面捷徑一樣會自動建好、而且路徑是對的。

需要的東西（你的電腦都已經有）：Node.js、Claude Code（已登入）、Codex CLI（已用 ChatGPT 帳號登入）、Microsoft Edge。

## 雲端版（Oracle 免費主機，家裡電腦不用開）

同一個工作台也可以放在 Oracle 的免費雲端主機上，24 小時開著，公司、家裡、手機都用瀏覽器打開網址就能用。
安裝步驟見對話裡的說明；裝好之後：

- 第一次進去先到右邊「帳號」分頁登入 Claude 和 Codex（都用你自己的月費帳號）。
- 把家裡的產品資料夾壓成 zip，按左上角 ⇪ 匯入；做好的檔案在「檔案」分頁下載，或按「下載整個產品」打包帶回家。
- 雲端沒有 Bambu Studio：最後的切片回家在 Bambu Studio 開 STEP／3MF 做。
- 「設定」可以換密碼；拿到新版工作台 zip 時，在「設定 → 更新工作台」上傳就好。

## 在公司／手機使用（家裡電腦版：遠端存取，免費）

工作台跑在家裡這台電腦上，用 Tailscale（個人版免費）給它一個只有你知道的網址，公司電腦或手機打開網址、輸入密碼就能用。公司電腦不用裝任何東西。

在家裡電腦打開工作台 → 右邊「遠端」分頁，照著 4 步做：

1. **設定登入密碼**（至少 8 個字）。
2. **安裝 Tailscale**：按「下載 Tailscale」，裝好後點右下角工作列的 Tailscale 圖示，用 Google 帳號登入。
3. **按「開啟遠端存取」**。第一次會出現「打開允許頁面」，在那個網頁按允許，再回來按一次開啟。成功後會顯示你的網址和 QR code（手機掃描就能開）。
4. **按「設定插電時不睡眠」**，不然電腦睡著時外面會連不到。

開啟後，電腦開機會自動在背景啟動工作台，不用先打開視窗。

注意：
- 家裡電腦要開機、連網。關機或睡眠時從外面連不到（登入頁會提示）。
- 遠端時可以聊天、看圖、下載檔案（STEP、3MF 等），但「在檔案總管打開」只有在家裡電腦才有。
- 從外面連進來的裝置會記住登入 30 天。換密碼後，其他裝置都要重新登入。
- 密碼連續打錯 5 次會鎖 10 分鐘。

## 畫面

| 區域 | 功能 |
|---|---|
| 左邊 | 選產品、＋開新產品（取代以前的 bat）、對話紀錄（依日期分組）、搜尋所有紀錄 |
| 中間 | 對話。上方可改標題、存成紀錄、打開資料夾 |
| 下方 | 選模式與兩邊的模型，輸入訊息。可拖曳或貼上圖片當附件 |
| 右邊 | 額度（兩邊的 5 小時與每週用量、何時重置）、檔案（瀏覽產品資料夾、預覽圖片、附加到訊息、下載）、環境檢查、遠端存取、設定 |

## 四種模式

- **Claude**：只問 Claude。直接在產品資料夾建模、驗證、切片。
- **Codex**：只問 Codex（GPT）。
- **交叉驗證**：Claude 先做 → Codex 獨立審查（會自己讀檔量測）→ Claude 用工具驗證並修正。可以選 1–3 輪，最後 Claude 給結論和要你決定的事。
- **同時問**：同一個問題兩邊各自回答，並排比較。

兩邊都會記得同一個對話之前的內容；另一邊不在場時說過的話，下次會自動補給它看。

## 紀錄

- 所有對話自動存在 `C:\Users\你的帳號\.makersense-workbench\threads\`，關掉再開都在。
- 按「⇩ 存成紀錄」會在產品資料夾的 `_records\` 存一份 Markdown，方便留檔或傳給別人。
- 上傳的附件放在產品資料夾的 `_inbox\`。

## 快捷鍵

`Enter` 送出　`Shift+Enter` 換行　`Ctrl+N` 新對話　`Ctrl+K` 搜尋紀錄　`Esc` 關閉圖片

## 常見問題

- **Claude 額度顯示「憑證過期」**：在工作台問 Claude 任何一句話，Claude Code 會自動更新登入，之後就會顯示。
- **Codex 額度沒出現**：Codex 的額度是從它最後一次使用的紀錄讀出來的，先用一次 Codex 就會有。
- **Codex 模型清單**：預設會用你 Codex 設定裡的模型。想在選單加別的模型，到「設定 → Codex 模型清單」加一行，例如 `gpt-5.5|GPT-5.5`。
- **權限**：Claude 預設是「全自動」（可以跑 Python 建模、切片）。只想讓它改檔案的話，到「設定」改成「只能讀寫檔案」。Codex 只能動產品資料夾。
- **關掉視窗後**：沒開遠端存取時，背景程式閒置 20 分鐘會自己結束，下次開捷徑會自動再啟動；開了遠端存取就會一直在背景待命。
- **出問題時**：看右邊「環境」頁。紀錄檔在 `C:\Users\你的帳號\.makersense-workbench\server.log`。

舊的 `開新產品.bat`、`打開舊產品.bat` 已經用不到，可以刪掉（`_template` 資料夾要留著，開新產品會用到）。
