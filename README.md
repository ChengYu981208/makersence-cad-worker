# MAKERSENSE 工作台（GitHub Codespaces 版）

在雲端同時用 Claude 和 Codex（GPT）開發 3D 列印商品。用你自己的月費帳號，不用付費 API，家裡電腦不用開。

## 怎麼打開
1. 到 https://github.com/codespaces ，找到這個 Codespace，按它打開（休眠中的話會自動開機，約 1 分鐘）。
2. 開好後會自動跳出「MAKERSENSE 工作台」分頁。沒跳出來的話：下方「連接埠（PORTS）」分頁 → 5888 那一列 → 按地球圖示。
3. 那個工作台網址可以加到書籤；Codespace 開著時，公司電腦和手機登入 GitHub 後直接打開網址就能用。

## 第一次使用
- 右邊「帳號」分頁：登入 Claude 和 Codex。
- 右邊「設定 → 更新工作台」：上傳 MAKERSENSE_Workbench.zip，載入你的規則、技能和匹克球拍專案。
- 左上 ⇪：匯入家裡電腦的產品資料夾（先壓成 zip）。

## 注意
- 每月免費 120 核心小時（這台 2 核心＝約 60 小時）。沒在用會自動休眠，不會一直扣時數。
- Codespace 連續 30 天沒打開會被 GitHub 刪除，裡面的檔案也會不見：重要的產品記得在「檔案」分頁按「下載整個產品」備份。
- 你的產品檔案和登入資料存在 Codespace 裡，不會上傳到這個（公開的）程式庫。
